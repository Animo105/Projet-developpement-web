# Projet de développement d'application web

Projet scolaire de développement web réalisé en équipe de 4, utilisant **Laravel** pour le backend et **Vue.js avec Inertia.js** pour l'interface utilisateur.

> **Note concernant le dépôt :** Le dépôt Git original n'étant plus disponible, ce dépôt a été recréé à partir des fichiers du projet. L'historique des commits originaux n'as pas été conservé il est donc impossible de retracer les contributions individuelle de chaque membre.
